# AI Fraud Detection

This project is designed to detect fraudulent transactions using Artificial Intelligence and Machine Learning.

## Features

- Fraud transaction detection
- Machine Learning based prediction
- Transaction data analysis
- Fraud and legitimate transaction classification

## Technologies Used

- Python
- Machine Learning
- Pandas
- NumPy
- Scikit-learn

## Project Goal

The goal of this project is to identify potentially fraudulent transactions and help reduce financial fraud.
